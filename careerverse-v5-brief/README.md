# Brief CareerVerse V5

## Utilisation

1. Décompresse ce dossier dans ton repo sous `docs/v5-brief/`, puis commit et push (Claude Code dans le cloud ne voit que GitHub).
2. Ouvre Claude Code sur le repo.
3. Modèle **Claude Opus 5.5**, effort **High**.
4. Colle le contenu de `PROMPT.md`.

## Contenu

- `PROMPT.md` : le prompt.
- `audit/AUDIT_V4.md` et `audit/img/` : mesures, captures annotées, avant/après.
- `prototype/` : patch du prototype V5 et notes.
